# DiffCalc Finance Pro

A terminal-based (TUI) personal finance tracker built with [Textual](https://textual.textualize.io/) and SQLAlchemy, covering net worth tracking, investment holdings, goal-based asset allocation, and cash flow projection.

This repository is the companion codebase to a case study on **spec-driven development (SDD)** with AI: an exploration of what it looks like to have an LLM author effectively all of the application's code, while the engineer focuses on directing the software's *purpose* (requirements) and *charter* (architecture, standards, conventions). No code in this repository was written directly by hand — it was generated by an AI coding agent under close human direction and review.

If you're here from the article, the interesting parts of this repo are:

- **[specs/](specs/)** — The canonical specifications (requirements, data model, UI flows, and the "technical charter" that governed all generated code) plus working artefacts (ADRs, slice logs) created along the way. `specs/README.md` explains how these are organized and how they were used to drive development.
- **[chat-logs/](chat-logs/)** — The prompt log referenced in the article: the actual sequence of prompts used to take this project from a blank repository to a working application.
- **[src/](src/)** — The generated application itself. Several subdirectories (e.g. `src/personal_finance/domain/`, `src/personal_finance/service/`) have their own `README.md` describing layer-specific conventions that emerged during development.

## What the application does

Personal Finance SDD replaces a manual spreadsheet-based personal finance workflow with three modules:

- **Balance Sheet** — Track bank accounts, investment accounts, and their holdings (cash, GICs, and listed securities priced via a live market data lookup). View net worth, current vs. long-term classification, and an "amount left to invest" calculation.
- **Goals** — Define savings/investment goals, allocate whole investment accounts or a portion of bank cash toward them, and track progress against target asset-class allocations.
- **Cash Flow** — Model income, household expenses, and recurring automated contributions to project monthly and annual cash flow.

All monetary and quantity data is tracked on an effective-date timeline, so the application can answer "what did my finances look like as of date X" rather than only reflecting the present moment.

## Running it

Requires Python 3.12+. The project uses a local virtual environment (no `hatch`/`uv` required on PATH).

```bash
# Create and activate a virtual environment, then install the project with dev dependencies
python3.12 -m venv .venv
.venv/bin/pip install -e ".[dev]"

# Seed the database (reads config.toml for persons, asset classes, etc.)
.venv/bin/python scripts/seed_sample_data.py

# Run the app
.venv/bin/personal-finance
```

Application data (SQLite database, logs) is stored in a platform-specific data directory (`~/.local/share/diffcalc-finance-pro/` on Linux). To wipe the database and reseed from scratch:

```bash
./reset-db.sh
```

To run the test suite:

```bash
.venv/bin/pytest
```
