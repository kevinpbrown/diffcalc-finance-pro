Next we will begin with the Goals screens. When a user lands on the goals module, the screen will display a table of all existing goals with the following headings:
- Name: always editable
- Goal: Manual goals are editable, but 'Present value' and 'No target' goals are not. All goals have the ellipses "..." attached to their values so the the GoalValueDialog can be reopened to edit the type and its details
- Investment allocation: current total values of all accounts assigned to this goal. The value is not editable, but the " > " button exists to open the `Select account(s)` dialog. That dialog will list all accounts in a scrollable checkbox select list; accounts already committed to another Goal should be grayed out but still displayed.
- Bank Account Allocation: Entry box for each row with a "..." next to it. If the "..." is selected, a dialog pops up with a checkbox that says "Fill difference from bank accounts". If selected, then the entry box will actually be disabled and the value will be the difference between the goal's value and the Investment Allocation
- Difference: Static value showing the distance away from the goal.

If the bank accounts are overclaimed, then a warning will display under the table: "Bank account is overclaimed by $X"

Operations
INS - Adds a new row to the table. It will show an extended version of the `GoalValueDialog` that includes an additional Name value at the top. 
DEL: Deletes the row currently with a focused element (after confirming with a Yes/No)
F3 - Allocation: Switched to the allocation view (stand by on that, we'll create a new context window for that)

The Goal creation and Goal value editor dialogs will share the following fields:
- Type: Manual, Present value or No target
For manual:
- Value
For present value:
- Future value
- Savings start
- Maturity date
- Discount rate
- Current goal: calculated as the amount that we should have assuming the current effective date ($0 if before Savings start, the full future value if after Maturity date)
- Monthly payment: calculated monthly payment required
