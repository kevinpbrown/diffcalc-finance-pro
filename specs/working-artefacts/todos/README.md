# Deferred Refactoring Notes and R&D

Stay focused on the current vertical slice. When you notice refactoring opportunities, architectural issues, or follow-up research that should not interrupt the slice, capture that work here instead of expanding the current scope.

Use this directory for:
- Deferred refactoring notes
- R&D findings that may inform a future slice
- Technical debt observations that are too small or speculative for an ADR

Do not use this directory for canonical requirements or active slice tracking.
